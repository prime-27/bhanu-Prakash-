# Universe journey

The whole scroll journey of stargazinghyderabad.com on a page of its own: 13 stops from a hillside in Hyderabad to the Big Bang, with every physics effect. It shows the visuals only: no portfolio sections, captions or information bar. The captions are still in the page, hidden by one CSS rule (`.cap,.hud{display:none!important}`); delete that rule to bring them back.

It uses the site's own engine, `js/universe.js`, so any change there shows up here too. Open it from the site at `/extras/universe-journey/` (for example with `python3 -m http.server` from the repository root).
