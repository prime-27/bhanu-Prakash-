# Universe journey

The whole scroll journey of stargazinghyderabad.com on a page of its own: 13 stops from a hillside in Hyderabad to the Big Bang, with every physics effect, a caption card for each stop and the distance readout. The portfolio sections are left out.

It uses the site's own engine, `js/universe.js`, so any change there shows up here too. Open it from the site at `/extras/universe-journey/` (for example with `python3 -m http.server` from the repository root).
